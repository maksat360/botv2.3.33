# V2 MES System

**Производственная MES-система внутри Telegram**

Управляйте всем циклом производства: от сырья до готовой продукции. Это не просто бот для зарплат. Это инструмент управления производством в реальном времени.

## 🚀 Быстрый старт

### 1. Получить токен
Напишите [@BotFather](https://t.me/BotFather) в Telegram и создайте нового бота. Получите токен.

### 2. Установка

```bash
chmod +x install.sh start.sh
./install.sh
```

### 3. Настройка
Откройте `config.py` и вставьте токен:
```python
BOT_TOKEN = "ваш_токен_от_BotFather"
```

### 4. Запуск
```bash
./start.sh
```

### 5. Вход
Напишите боту `/start`. Войдите с логином **Макс** и паролем **123456789**.

## 📋 Возможности

### 👥 Роли
- **Начальник** — дэшборд, все партии, зарплаты, статистика брака
- **Технолог** — управление процессами, обработка брака
- **Табельщик** — запись часов сотрудников
- **Бухгалтер** — загрузка зарплатных отчётов
- **Сотрудник** — свои задачи, брак, зарплата

### 🏭 Производственный конвейер (граф зависимостей)
Гибкий конвейер с поддержкой:
- **Процесс 0** — создание партий (раскройщик)
- **Параллельные процессы** — несколько процессов одновременно
- **Опциональные зависимости** — процесс может не участвовать
- **Точки сбора** — процесс ждёт завершения нескольких других
- **Жёсткие цепочки** — строгая последовательность

Настройка через Excel (`конвейер_настройки.xlsx`):

| ID | Название | Ответственный | Зависимость от | Обязательные | Цена |
|----|----------|--------------|----------------|--------------|------|
| 0 | Раскрой | Максат | — | — | 12 |
| 1 | Процесс 1 | | 0 | 0 | |
| 2 | Процесс 2 | Гулжамал | 0 | 0 | |
| 3 | Процесс 3 (опц.) | Нуржамал | 0 | — | |
| 4 | Сборка | Нуржамал | 1,2,3 | 1,2 | |
| 5-10 | Цепочка | ... | предыдущий | предыдущий | |

### 📸 Брак
- Фотофиксация дефектов
- Обработка технологом
- Статистика для начальника

### 💰 Зарплаты
- Загрузка отчётов бухгалтером
- Просмотр своей зарплаты сотрудником
- Все зарплаты для начальника
- Архив версий

### ⏱ Учёт времени
- Запись смен табельщиком
- Просмотр своих часов сотрудником

## 🔧 Настройка конвейера

Откройте `cloud_storage/конвейер_настройки.xlsx`. Колонки:

- **ID** — номер процесса (0 — создание партий)
- **Название** — описание этапа
- **Ответственный** — кто выполняет (логин сотрудника)
- **Зависимость от** — ID процессов, от которых зависит (через запятую)
- **Обязательные зависимости** — ID обязательных процессов
- **Цена** — стоимость обработки одной партии
- **Норма времени (мин)** — сколько минут длится этап
- **Требует фотоотчёта** — Да/Нет

### Пример графа зависимостей

```
Процесс 0 (раскройщик) создаёт партии
    │
    ├──→ Процесс 1 (параллельно)
    ├──→ Процесс 2 (параллельно)
    └──→ Процесс 3 (опционально)
            │
            └──→ Процесс 4 (ждёт 1 и 2)
                    │
                    └──→ 5 → 6 → 7 → 8 → 9 → 10 (цепочка)
```

## 👤 Назначение процессов сотрудникам

В `пользователи.xlsx` есть колонка **процессы**. Укажите ID процессов через запятую:

| логин | процессы |
|-------|----------|
| Максат | 0,7 |
| Гулжамал | 2,8 |
| Нуржамал | 4,3 |
| Омка | 5,9 |

Сотрудник видит только свои процессы в меню «Мои задачи».

## 🔒 Безопасность

- Пароли хешируются (SHA-256)
- Пароль уникален глобально
- Сотрудник видит только свои данные
- Данные хранятся локально
